Core Principles

Vibe Coding 4가지 핵심 원칙

1. Intent over Syntax

문법보다 의도를 전달하라

// Bad "for loop으로 FASTA 파싱해줘" // Good "GC content > 60% 서열만 추출해줘"

2. Small Steps

작은 단위로 반복하라

// Bad "전체 파이프라인 만들어줘" // Good "Step 1: PDB 파싱 → Step 2: ..."

3. Context is King

맥락을 풍부하게 제공하라

// 데이터 유형, 형식, 크기, // 원하는 출력, 사용할 라이브러리 // 모두 프롬프트에 포함

4. You = Reviewer

당신이 검증자다

// AI가 생성 → 당신이 검증 // 특히 생물학적 타당성! // EGFR score > TP53 맞는지?
Prompting

좋은 프롬프트 vs 나쁜 프롬프트

Bad Prompt

"유전자 분석해줘" "도킹 돌려줘" "그래프 그려줘"

× 모호함, 맥락 없음, AI가 추측해야 함

Good Prompt

"이 CSV의 Gene Symbol 컬럼에서 유전자 목록을 읽어서 Enrichr API로 GO enrichment 분석 후 상위 20개를 barplot으로. p-value < 0.05 기준. pandas + matplotlib 사용."

✓ 구체적, 맥락 풍부, 도구 지정

Template

프롬프트 템플릿

[역할] 나는 생물정보학 대학원생이야. [맥락] RNA-seq 데이터를 분석하고 있어. DEG 리스트가 1,200개 유전자. HepG2 vs 정상 간세포 비교 실험이야. [목표] GO enrichment analysis를 하고 싶어. [구체적] - enrichR API 사용 - GO_Biological_Process_2023 DB - 상위 20개 pathway barplot - p-value < 0.05 [출력] DataFrame + PNG (300 DPI) [제약] pandas, matplotlib, requests만 사용

한국어 프롬프트 OK! 단, 기술 용어는 영어 혼용 시 정확도 UP

Caution

주의해야 할 4가지 함정

Hallucination

존재하지 않는 라이브러리/함수 생성
→ import가 실제로 작동하는지 확인

Security

환자 데이터, 유전체 데이터 노출 위험
→ 개인정보보호법, HIPAA 준수

Reproducibility

같은 프롬프트 ≠ 같은 결과
→ requirements.txt + seed 고정

Over-reliance

코드를 이해 못하면 디버깅 불가
→ 생물정보학 기초 지식 여전히 필수

Vibe Coding in Action

이 파이프라인을 Vibe Coding으로 만든 방법

# Claude Code에 입력한 실제 프롬프트 "REINVENT4로 생성한 50개 SMILES 파일이 있어. 이 분자들을 AutoDock Vina로 도킹하는 자동화 스크립트를 만들어줘. 구체적으로: 1. RDKit으로 SMILES → 3D 구조 변환 (ETKDG 방법) 2. Meeko로 PDBQT 형식 변환 3. AutoDock Vina 실행 (exhaustiveness=16) 4. 결과를 CSV로 정리 (분자명, Vina score, 최적 포즈) 5. 상위 10개의 결합 구조를 SDF로 저장 receptor.pdbqt는 이미 준비되어 있어. box center: [16.3, 28.1, 31.4], size: [24, 24, 24]"

→ Claude Code가 ~200줄의 완전한 파이프라인 스크립트 생성

핵심 발견

Vibe Coding Magic

Vibe Coding으로 도구 연결한 방법

# 프롬프트 1: REINVENT4 → Vina 연결 "REINVENT4가 생성한 SMILES CSV를 읽어서 각 분자를 Vina로 도킹하고 결과를 정리하는 파이프라인 만들어줘" # 프롬프트 2: Vina → Boltz-2 연결 "도킹 결과 상위 20개를 Boltz-2 YAML 입력으로 변환해줘. 단백질 서열은 receptor.fasta에서 읽고, 리간드 SMILES는 도킹 결과 CSV에서 가져와줘" # 프롬프트 3: 통합 분석 "Vina score, Boltz-2 affinity, QED, MW를 하나의 DataFrame으로 합치고 radar chart + heatmap으로 시각화해줘" # 프롬프트 4: 디버깅 "Meeko에서 'Cannot kekulize mol' 에러가 나. 방향족 질소가 있는 SMILES에서 발생하는 것 같아. 고쳐줘"

Workflow

완전한 Vibe Coding 워크플로우

1. PLAN "무엇을 만들 것인가?" 자연어로 정리 ↓ 2. PROMPT 명확한 의도 + 풍부한 맥락 + 구체적 요구사항 ↓ 3. GENERATE AI가 코드 생성 ↓ 4. REVIEW 코드 맞는가? + 결과가 생물학적으로 타당한가? ★ 가장 중요 ↓ 5. ITERATE 수정 요청 → 3번으로 돌아감 ↓ 6. TEST 자동화된 테스트 + 수동 검증 ↓ 7. DOCUMENT README, 프롬프트 기록, 재현성 확보
