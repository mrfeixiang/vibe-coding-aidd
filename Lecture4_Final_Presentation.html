Recap

4가지 원칙을 체화했나요?

1. Intent over Syntax

"GC content가 60% 이상인 서열만 추출해줘"
Lecture 1에서 배웠고, Lecture 3에서 실전 적용

2. Small Steps

REINVENT4 → RDKit → Vina → Boltz-2

3. Context is King

box center, exhaustiveness, 단백질 서열까지

EGFR 점수 검증, Meeko 에러 수정, 생물학적 타당성
AI가 틀릴 때 발견하는 것이 여러분의 가치

New Tool

Claude Science: AI 연구 워크스테이션

Claude Science란?

  • Anthropic의 생명과학 전용 AI 분석 플랫폼
  • 24+개 MCP 커넥터 내장
  • 로컬 실행 — 데이터가 서버 밖으로 나가지 않음
  • 자동 Conda 환경 관리
  • PubMed, ChEMBL, ClinicalTrials 직접 조회
  • Python/R 코드 생성 및 실행

내장 데이터 커넥터

문헌 PubMed, bioRxiv, Clinical Trials 유전체 BioMart, Variants, Expression 단백질 Protein Annotation, Structures 약물 ChEMBL, Drug Regulatory (FDA) 화학 ZINC, Ketcher Chemistry 기타 CellGuide, Cancer Models, RNA

하나의 대화창에서 6개 데이터베이스를 동시에 조회 — 더 이상 탭을 넘나들며 Copy-Paste 할 필요 없음

Claude Science Demo

Claude Science 실전 예시

A. 타겟 조사

"TEAD4 항암 타겟 최신 동향 조사해줘. 1) PubMed에서 2024-2025 리뷰 검색 2) ChEMBL에서 TEAD 억제제 IC50 데이터 3) ClinicalTrials에서 관련 임상시험 4) PDB 공결정 구조 ID 정리" → 자동으로 3개 커넥터 호출 + 표 생성

B. 결과 교차 검증

"Boltz-2 예측 결과 5개 분자의 EGFR 결합 친화력을 교차 검증해줘. 1) 이 골격의 문헌 활성 보고 2) ChEMBL 유사 구조 IC50 데이터 3) hERG 등 off-target 위험 확인" → 문헌 + DB 기반 자동 검증 보고서

C. SAR 분석

"ChEMBL에서 JAK2 IC50 < 1μM 화합물을 Murcko scaffold로 클러스터링. 2023년 이후 신규 골격 식별." → 무료 구효관계 분석 도구

D. 경쟁 인텔리전스

"PPI 억제제 2024-2025 임상 파이프라인 정리해줘. 어떤 회사가 추진 중? 가장 핫한 타겟은? 파이프라인 히트맵." → ClinicalTrials + PubMed 통합 분석
Integration

Claude Science + Claude Code = 최강 조합

Claude Science "연구 두뇌" — 문헌, DB, 분석 ↕ insights & data exchange Claude Code "엔지니어링 손" — 코드, 파이프라인, 자동화

Advanced Case Study

CovLib: 공유결합 억제제 설계 파이프라인

CovLib이란?

  • Cys/Ser 타겟 공유결합 억제제 자동 설계
  • Vibe Coding으로 전체 파이프라인 구축
  • 반응성 워헤드 라이브러리 탑재
  • 자동 Linker 생성 & 최적화
  • Vina + Boltz-2 이중 검증 내장
Covalent Automated Open Source

파이프라인 흐름

입력: 단백질 PDB + 타겟 잔기 (Cys/Ser) ↓ 1. 결합 부위 분석 (fpocket) 2. 리간드 골격 선택/생성 3. 워헤드 부착 (클로로아세타미드, 아크릴아미드, 비닐술폰 등) 4. 3D 구조 생성 (ETKDG) 5. AutoDock Vina 도킹 6. Boltz-2 친화력 검증 7. 결과 랭킹 & 시각화 ↓ 출력: 순위별 후보 + 3D 포즈 + 보고서

Debugging

실전 디버깅 패턴

패턴 1: 에러 직접 전달

"이 에러가 발생했어: Cannot kekulize mol 방향족 질소가 있는 SMILES에서 발생. 고쳐줘." → AI가 RDKit 표준화 코드 추가

패턴 2: 버전 충돌

"Meeko 0.7.1을 쓰고 있는데 AI가 0.6 API로 코드를 썼어. 현재 버전 API에 맞게 수정해줘." → 항상 버전을 프롬프트에 명시

패턴 3: YAML/포맷 이슈

"Boltz-2 YAML 파싱 에러. 2-space indent, no tabs로 다시 생성해줘." → 포맷 제약을 명시적으로 지정

패턴 4: 결과 검증 실패

"TP53 druggability가 90점 나왔는데 실제로는 undruggable로 알려져 있어. 스코어링 로직을 재검토해줘." → 도메인 지식으로 AI 오류 발견

핵심: 에러를 두려워하지 말고 AI에게 전달하는 습관을 기르세요

검증 체크리스트

  • import가 실제 존재하는지
  • 양성 대조군 (known active) 테스트
  • 음성 대조군 (known inactive) 테스트
  • 결과의 생물학적 타당성

프롬프트를 저장하지 않으면, 6개월 후에 같은 코드를 만들 수 없습니다.

Lessons Learned

4주간 배운 교훈

실수왜 문제인가해결법
"전체 파이프라인 만들어줘" AI가 200줄+ 코드를 한 번에 생성 → 에러 추적 불가 5-6단계로 분리
import를 확인하지 않음 AI가 존재하지 않는 라이브러리 사용 모든 import 수동 확인
도킹 box 위치를 AI에게 맡김 AI는 3D 구조를 "보지" 못함 PyMOL로 직접 확인 후 좌표 전달
양성/음성 대조군 없이 분석 결과가 맞는지 틀리는지 판단 불가 알려진 화합물로 먼저 테스트
결과를 무조건 신뢰 EGFR을 undruggable이라 한다면? 도메인 지식으로 상식 점검
프롬프트를 저장하지 않음 재현 불가능, 같은 실수 반복 prompts/ 디렉토리 + CLAUDE.md
Practice

과제 케이스: TEAD 억제제 설계

왜 TEAD인가?

  • Hippo 신호전달 경로 핵심 전사인자
  • 간암, 폐암, 위암과 밀접한 관련
  • IK-930, VT3989 등 임상 진입 억제제 존재
  • 보존된 지질 포켓 (Lipid Pocket)
  • Cys367 → 공유결합 전략 적용 가능
  • PDB 구조 풍부: 7CNL, 7CMM, 8P0M

전체 워크플로우

Phase 1 타겟 조사 (Claude Science) UniProt, PDB, ChEMBL 조회 ↓ Phase 2 분자 생성 (REINVENT4) 종자 분자 → 30+ 후보 생성 ↓ Phase 3 친화력 평가 Boltz-2 또는 AutoDock Vina ↓ Phase 4 분석 & 보고서 작성 Top 5 + 대조군 비교 + 시각화

이 전체 과정을 하루 안에 Vibe Coding으로 완료할 수 있습니다

Core Message

여러분의 핵심 공식

도메인 지식 ← Drug Discovery 이해 ← 여러분 + 의도 표현 ← 무엇을 분석할지 설명 ← 여러분 + AI 도구 활용 ← Claude Code/Science 활용 ← 여러분 + 코드 생성 ← 파이프라인, 분석, 자동화 ← AI + 결과 검증 ← 생물학적 타당성 확인 ← 여러분 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ = 유효한 약물 후보

5개 항목 중 4개가 여러분에게 달려 있습니다.
AI는 도구이고, 여러분이 과학자입니다.

Final Thought

두 가지 미래

미래 A

"AI가 코드를 써주니까
나는 공부할 필요 없어."

→ AI가 틀려도 모르고
→ 결과를 검증할 수 없고
→ 도메인 지식 없이 표류

미래 B

"AI가 코드를 써주니까
나는 과학에 집중할 수 있어."

→ 도메인 지식으로 AI를 감독
→ 더 야심찬 연구 질문 도전
→ 10배 빠른 과학적 발견

AI는 약물화학자를 대체하지 않는다.
하지만 AI를 쓰는 약물화학자가 쓰지 않는 약물화학자를 대체한다.
