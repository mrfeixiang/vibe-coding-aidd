化学 · Warhead Chemistry

Cys / Ser 反应性弹头(Warhead)

Cysteine 靶向弹头（24种）

丙烯酰胺 氯乙酰胺 丙炔酰胺 乙烯基磺酰胺 氰基丙烯酰胺 马来酰亚胺 丁炔酰胺 卤代乙酰胺

Serine 靶向弹头（19种）

磺酰氟 环氧化物 β-内酰胺 硼酸 醛 腈 活性酯 膦酰氟

自动弹头识别 (SMARTS)

# Cysteine 反应性
丙烯酰胺:      [CH2]=[CH]-[C](=O)-[N]
氯乙酰:        [Cl]-[CH2]-[C](=O)-[N]
乙烯基砜:      [CH2]=[CH]-[S](=O)(=O)

# Serine 反应性
磺酰 F:       [S](=O)(=O)-[F]
环氧化物:      [C]1-[O]-[C]1
硼酸:          [B](-[OH])-[OH]

核心公式

dest = dsite − LEWF

d_est 越接近 0 越理想 · 阈值: −5Å < d_est < 5Å（宽松）/ −3Å < d_est < 3Å（严格）
