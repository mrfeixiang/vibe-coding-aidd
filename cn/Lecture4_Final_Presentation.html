Claude Science 实战示例

A. 靶点调研

"帮我调研TEAD4作为抗癌靶点的最新动态。 1) 在PubMed搜索2024-2025年的综述 2) 在ChEMBL查询TEAD抑制剂的IC50数据 3) 在ClinicalTrials检索相关临床试验 4) 整理PDB共结晶结构ID" → 自动调用3个连接器 + 生成表格

B. 结果交叉验证

"帮我交叉验证Boltz-2预测的5个分子 对EGFR的结合亲和力。 1) 该骨架的文献活性报告 2) ChEMBL中相似结构的IC50数据 3) hERG等脱靶风险检查" → 基于文献 + 数据库的自动验证报告

C. SAR 分析

"从ChEMBL获取JAK2 IC50 < 1μM的化合物， 按Murcko骨架聚类。 识别2023年以后的新骨架。" → 免费的构效关系分析工具

D. 竞争情报

"整理PPI抑制剂2024-2025年的临床管线。 哪些公司在推进？ 最热门的靶点是什么？生成管线热力图。" → ClinicalTrials + PubMed 整合分析

Advanced Prompting

Prompt 进阶：Level 2

初级 Prompt（Lecture 1-2）

"帮我计算这个FASTA文件的 GC含量。" → 单一任务，单一输出 → 上下文最少 → 一次完成

高级 Prompt（Lecture 4）

"将REINVENT4 CSV + Vina结果 + Boltz-2 输出整合为一个分析仪表盘。 遵循CLAUDE.md中定义的规范。 失败的分子记录到日志中并跳过。 最终输出：interactive HTML报告。" → 多工具连接 → 错误处理指令 → 输出格式规范

将项目上下文持久化到文件中

错误传递

Debugging

实战调试模式

模式 1：直接传递错误

"出现了这个错误： Cannot kekulize mol 在含有芳香氮的SMILES中发生。 帮我修复。" → AI添加RDKit标准化代码

模式 2：版本冲突

"我用的是Meeko 0.7.1， 但AI按0.6版API写的代码。 请按当前版本API修改。" → 务必在Prompt中注明版本

模式 3：YAML/格式问题

"Boltz-2 YAML解析报错。 请用2-space indent, no tabs 重新生成。" → 明确指定格式约束

模式 4：结果验证失败

"TP53的druggability得了90分， 但实际上它被认为是undruggable。 请重新审查评分逻辑。" → 用领域知识发现AI的错误

关键：不要害怕错误，培养将错误传递给AI的习惯

Best Practices

可复现性 & 最佳实践：专业 Vibe Coder 的习惯

📦

环境锁定

  • requirements.txt 必备
  • environment.yml 推荐
  • 明确 Python 版本
  • 记录 GPU 驱动版本
📝

Prompt 归档

  • 创建 prompts/ 目录
  • 保存使用过的 Prompt
  • 记录 AI 模型版本
  • 同时记录修改过程
🔍

验证清单

  • import 是否真实存在
  • 阳性对照组（known active）测试
  • 阴性对照组（known inactive）测试
  • 结果的生物学合理性

如果不保存 Prompt，6个月后你将无法重现相同的代码。
Prompt 是一种新形态的源代码。

Lessons Learned

四周学到的教训

错误为什么是问题解决方法
"帮我做完整个流水线" AI一次生成200行以上代码 → 无法追踪错误 分成5-6个步骤
不检查 import AI使用不存在的库 手动确认所有 import
让AI决定对接 box 位置 AI无法"看到"3D结构 用PyMOL确认后传入坐标
没有阳性/阴性对照组就分析 无法判断结果对错 先用已知化合物测试
无条件信任结果 如果EGFR被判为undruggable？ 用领域知识进行常识检验
不保存 Prompt 无法复现，重复犯同样的错误 prompts/ 目录 + CLAUDE.md
Practice

作业案例：TEAD 抑制剂设计

为什么选 TEAD？

  • Hippo 信号通路核心转录因子
  • 与肝癌、肺癌、胃癌密切相关
  • IK-930、VT3989 等已进入临床的抑制剂存在
  • 保守的脂质口袋（Lipid Pocket）
  • Cys367 → 可应用共价策略
  • PDB 结构丰富：7CNL、7CMM、8P0M

完整工作流

Phase 1 靶点调研（Claude Science） UniProt、PDB、ChEMBL 查询 ↓ Phase 2 分子生成（REINVENT4） 种子分子 → 30+ 候选物生成 ↓ Phase 3 亲和力评估 Boltz-2 或 AutoDock Vina ↓ Phase 4 分析 & 报告撰写 Top 5 + 对照组比较 + 可视化

整个过程可以通过 Vibe Coding 在一天之内完成
